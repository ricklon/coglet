Connect to agent-hub

Give the robot Wi-Fi and a hub to talk to, then try its tools. Still no servos needed.

Connect it to agent-hub

You need an agent-hub running and reachable from the robot's Wi-Fi. Its check-in endpoint is on port 8003 by default.

1
Add Wi-Fi (2.4 GHz): !wifi YourSSID YourPassword
2
Point it at the hub: !server http://HUB_HOST:8003/xiaozhi/ota/. Use the hub's real address, not localhost. It reboots.
3
Reconnect the console and run !status. Expect an IP address, a Hub WebSocket URL and Session: listening.
4
Open the hub dashboard. The robot appears under its MAC address (!status shows it as Device id), labelled with its board (coglet-c3, coglet-c6 or coglet).
5
Talk to it. The hub greets it once, then say something. The console logs >> what it heard and << what it says, and the reply plays through the speaker. Press the BOOT button to stop a reply.

A hub with an enrollment token: use its HTTPS check-in URL with ?enrollment_token=..., typed here, never baked into a public build.

Troubleshooting
SymptomCheck
No IP in !status!wifi list; 2.4 GHz network; password. Re-add with !wifi
"Check-in ... failed: HTTP -1"Hub address or port wrong, or a firewall. From a computer on the same Wi-Fi: curl http://HUB_HOST:8003/xiaozhi/ota/
HTTP 401 at check-inThe hub wants an enrollment token in the URL
Session stuck on connectingThe hub's WebSocket URL (shown by !status) must be reachable from the robot
It hears nothing!mic status while talking; !quiet status must be off
No sound from replies!speaker, then !speaker vol 70
Test its MCP tools

MCP is Coglet's one interface: every command is a tool, listed on the hub dashboard once the session is up. They fall into groups:

  • Motion (once engaged): self.coglet.gaze, head, jaw, ears, lids, blink, animate.
  • Stopping: self.coglet.stop and release.
  • Modes and calibration: engage, calibrate, fit, explore, nudge, mark, confirm, save, test and more.
  • Voice and device: self.voice.quiet, volume, mic, Wi-Fi, hub URL, reboot, status.
  • By voice: "What's your volume?" or "Turn your volume down a bit."
  • Motion tools return errors until the robot is engaged, which needs every fitted servo calibrated. Anyone with hub access can engage it, so keep the servo supply switch in reach.
  • From Claude Code, through agent-hub's device proxy:
claude mcp add coglet -- python3 /path/to/agent-hub/scripts/device_mcp_proxy.py \
    --device YOUR_ROBOT_MAC --all-tools

The proxy is on agent-hub's main. Without --all-tools it exposes only tools that can't start motion. The full command list is in OPERATION.md.
