Flash the firmware

Put Coglet firmware on the XIAO from your browser. No tools to install.

Switch the servo supply off before you plug in USB. Opening the port can reset the board, and the servo rail switch is the only real emergency stop.

Every boot starts released, and a fresh board has no servo roles assigned, so flashing moves nothing. Calibration lives on the board: "erase" wipes it, so on a robot that's already calibrated, export it first (!coglet export).

Flash the firmware
1
Servo supply off. Plug the XIAO into this computer by USB-C.
2
Use Chrome or Edge on a desktop. Pick the card for your board. Click the button for your board and pick its port (on Linux usually /dev/ttyACM0).
3
A new board: let it erase. A calibrated robot: export calibration first and install without erasing.
4
If the port doesn't appear, hold the XIAO's BOOT button while plugging it in, then try again.
5
Done flashing? Open the Check page and run !status. It should name the board you flashed. You can flash the bare XIAO now, before any wiring; the wiring guide comes next.

Coglet S3 · "Computer"

XIAO ESP32-S3 Sense · 8MB · Camera (detected at boot)
INMP441 mic · MAX98357A amp · PCA9685
Wake word "Computer": a trained model, the most reliable.
This browser has no Web Serial. Use Chrome or Edge.

Coglet S3 · your own phrase

XIAO ESP32-S3 Sense · 8MB · Camera (detected at boot)
INMP441 mic · MAX98357A amp · PCA9685
Wake phrase "Hey Coglet" to start; change it any time with !wake PHRASE in the console on the Check page. Typed, not trained, so expect more misses and false wakes than "Computer".
This browser has no Web Serial. Use Chrome or Edge.

Coglet C3

XIAO ESP32-C3 · 4MB · No camera
INMP441 mic · MAX98357A amp · PCA9685
This browser has no Web Serial. Use Chrome or Edge.

Coglet C6

XIAO ESP32-C6 · 4MB · No camera · No wake word
INMP441 mic · MAX98357A amp · PCA9685
Not yet run on a robot: the pin map is unchecked on hardware.
This browser has no Web Serial. Use Chrome or Edge.

Both S3 builds use the same flash layout, so you can switch between them without erasing: Wi-Fi, hub and calibration stay. The first install of either onto an S3 flashed before 2026-10-27 moves the wake word storage to a larger partition. Settings live elsewhere and should survive it, but export calibration first, as for any install.
