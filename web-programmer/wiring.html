Wire a Coglet, step by step

One wire per step, in eight stages. Each stage ends with a check, so a mistake shows up where you made it. Every wire has an ID that matches hardware/wires.csv. Every board uses the same pads, so the S3 (the main board), the C3 and the C6 take the same harness. Back to the Web Programmer.

Before you start
  • The servo supply stays off and unplugged until the last wiring step, and no servo is plugged in.
  • Keep the servo-rail switch within reach whenever servo power is on. It is the emergency stop.
  • Unplug USB while you change wires. Check each stage before the next.

Pin and power reference: WIRING.md. After the last step, continue with servos in ASSEMBLY.md. These are build instructions, not a record of any robot having been built; what you saw at each check belongs in QUALIFICATION.md.
